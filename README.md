## ⚡ Local Setup & Preview
1. Clone or download this repository:
   ```bash
   git clone https://github.com/shreya-shetty205/portfolio.git
   cd portfolio
   ```
2. Open `index.html` in your browser or run a lightweight local server:
   ```bash
   npx serve .
   # or
   python -m http.server 8080
   ```
3. Visit `http://localhost:8080` in your web browser.
